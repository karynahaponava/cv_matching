# CV Matching 

Система для автоматизации работы сейлзов: парсинг резюме из Google Docs, обработка запросов из Telegram, семантический поиск с использованием ИИ-векторов и учет истории подач.

## Основной стек технологий
- **Backend:** FastAPI, Python, Pandas, Sentence-Transformers
- **Frontend:** Streamlit
- **Database:** PostgreSQL
- **Infrastructure:** Docker & Docker Compose

## Что нужно для запуска
1. Установленный [Git](https://git-scm.com/downloads)
2. Установленный [Docker Desktop](https://www.docker.com/products/docker-desktop/) (Python локально устанавливать не обязательно, всё работает в контейнерах)

## Установка и настройка

**1. Клонируйте репозиторий:**
```bash
git clone <ссылка_на_репозиторий>
cd cv_matching
```

**2. Настройте доступы:**

Создайте файл .env в корне проекта (смотрите пример всех необходимых переменных в .env.example).

Положите файл google_creds.json (ключ сервисного аккаунта Google) в корень проекта.

**3. Запустите проект через Docker:**

Выполните команду в терминале, чтобы собрать и запустить базу данных, бэкенд и интерфейс:

```Bash
docker-compose up --build
```

(При первом запуске Docker скачает необходимые образы, установит зависимости из requirements.txt и инициализирует базу данных. Это может занять несколько минут).

**4. Использование:**

После появления в терминале сообщения об успешном запуске сервисов, проект будет доступен по следующим адресам:

Интерфейс (Сайт): http://localhost:8501

API Документация (Swagger): http://localhost:8000/docs

В боковом меню интерфейса нажмите "Синхронизация", чтобы скачать данные и загрузить тексты резюме в векторную базу!

**Vacancies (Запросы):** Просмотр всех актуальных вакансий, загруженных из Google Таблиц. Здесь можно отфильтровать запросы по направлениям (отделам), посмотреть детальные требования и запустить ручную синхронизацию с таблицей.

**Telegram:** Ручной парсер Telegram-каналов. Позволяет в реальном времени вытянуть последние посты из любого открытого IT-канала, сохранить новые вакансии в базу или мгновенно отправить текст поста в ИИ-подбор кандидатов.

**Saved Vacancies:** База данных всех вакансий, собранных из Telegram (вручную или через фоновый парсер по расписанию). Отсюда можно в один клик запустить поиск подходящих кандидатов (UI) под любую сохраненную вакансию.
