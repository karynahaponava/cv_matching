
# CV Matching 

Система для автоматизации работы сейлзов: парсинг резюме из Google Docs, семантический поиск по ИИ-векторам и учет истории подач.

## Что нужно для запуска
1. Установленный [Python ](https://www.python.org/downloads/)
2. Установленный [Docker Desktop](https://www.docker.com/products/docker-desktop/)

## Установка и настройка

**1. Клонируйте репозиторий:**
```bash
git clone <ссылка_на_твой_репозиторий>
cd cv_matching

```

**2. Настройте доступы:**

-   Создайте файл `.env` в корне проекта (смотрите пример в `.env.example`).
    
-   Положите файл `google_creds.json` (ключ сервисного аккаунта Google) в корень проекта.
    

**3. Запустите базу данных (Postgres):**



```bash
docker-compose up -d

```

_(База данных и необходимые расширения создадутся автоматически)._

**4. Установите зависимости и запустите Бэкенд:** 

Откройте первый терминал и выполните:

```bash
pip install -r requirements.txt
uvicorn main:app --reload --port 8000

```

**5. Запустите Интерфейс (Сайт):** Откройте второй терминал и выполните:

```bash
streamlit run ui.py

```

Сайт откроется в браузере по адресу `http://localhost:8501`. В боковом меню нажмите **"Синхронизация"**, чтобы скачать данные из Excel и загрузить тексты резюме!
